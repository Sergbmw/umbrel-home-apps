# Sprut.hub для Umbrel

Экспериментальный пакет для переноса уже работающего Sprut.hub на подготовленном сервере. Сам по себе пакет не создаёт образ, не переносит данные и не настраивает контроллеры.

ПО и лицензия в пакет не входят: необходимы собственный образ и действующая лицензия. Для Zigbee требуется совместимый координатор. Производитель поддерживает фирменные стики Sprut; некоторые сторонние координаторы могут работать, но не поддерживаются производителем. Запуск на Mac mini и в Docker экспериментальный и не поддерживается Sprut.hub. Подробности: [поддерживаемые платформы](https://wiki.spruthub.ru/На_каких_платформах_работает_Sprut.hub) и [координаторы Zigbee](https://wiki.spruthub.ru/Как_работает_ZigBee).

Для этой конфигурации необходимы заранее подготовленный локальный реестр и образ, существующий том данных, каталог резервных копий, USB-адаптеры и смонтированная флешка. Пути указаны в `docker-compose.yml` и зависят от конкретного сервера. На другом сервере потребуется подготовка и проверка конфигурации.

Перед установкой остановите старый контейнер, сохраните проверенную резервную копию данных и подготовьте откат. Не запускайте две копии хаба одновременно: они могут обращаться к одним данным, портам и контроллерам. После установки проверьте устройства и резервирование на флешку.
